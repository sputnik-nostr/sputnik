# sputnik

A minimal, cross-platform Nostr client. WIP.

## Features

- Privacy-focused
- Not bloated (compared to other clients)
- Very good performance
- Support for [a reasonable number of NIPs](./docs/NIPS.md)
- Licensed under MIT
